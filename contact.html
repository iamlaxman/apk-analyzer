About the project & its developer

Built by a developer, for developers.

APK Analyzer Pro is an independent, open-source project — created to solve a real problem, and maintained by one person who actually uses it.

The story

Why this project exists

APK Analyzer Pro started as a personal tool. I kept running into the same problem: I needed to inspect Android packages, but every online analyzer wanted me to upload the APK to their server.

For internal builds, unreleased apps, or files I simply didn't want to hand to a third party, that was a non-starter. So I built the analyzer I actually wanted — one that runs entirely in the browser, parses the real binary formats, and never sends a single byte of the APK anywhere.

If analyzing an APK requires trusting someone else's server with your file, it isn't really private analysis. It's just uploaded analysis.

— The principle the whole project is built on

Everything you see — the binary AndroidManifest.xml decoder, the DEX header parser, the security scanner, the technology detector — runs on your machine, in your browser tab. No backend, no account, no upload.

Principles

Four rules the project will never break

Local by default

Your APK never leaves your device. Every operation runs client-side.

Real parsing

No mocks, no approximations. Actual AXML and DEX decoders written from scratch.

No accounts, no tracking

No signup, no cookies, no analytics. Nothing about you is collected.

Open source

Read the code, self-host it, modify it. Inspect what you're running.
