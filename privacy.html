Privacy Policy

A plain-language explanation of what APK Analyzer Pro does and doesn't do with your data. The short version: your APK never leaves your device, and we don't collect anything about you.

Privacy in one minute

What this policy actually says

Your APK never leaves your device. All analysis runs locally in your browser using JavaScript. No file contents are transmitted anywhere.
We don't use analytics or tracking. No Google Analytics, no Plausible, no Mixpanel — nothing that sends your activity anywhere.
No accounts, no cookies, no personal data. You don't sign up, and we have no profile about you.
Two third-party CDNs load static assets (Google Fonts, JSZip). These are subject to their own privacy policies.
Works offline after first load. Once cached, you can disconnect entirely and still analyze APKs.

Our commitment

APK Analyzer Pro was built around a single design constraint: the analysis must never require sending your APK anywhere. Everything else follows from that.

Traditional APK analysis services work by uploading your file to a server. That means the server operator — and anyone with access to their infrastructure — can see exactly what you're analyzing. For many users (security researchers, journalists, penetration testers, developers working on confidential apps) that's a non-starter.

We chose a different path. Every operation — reading the binary manifest, decoding DEX headers, scanning for technologies, running security checks — happens inside your browser tab. The APK is read from your disk into memory, processed, and never transmitted.

✓
You can verify this claim

Open your browser's developer tools, switch to the Network tab, and analyze an APK. You'll see no requests carrying your APK data — only static assets (HTML, CSS, JS, fonts) and the JSZip library from a public CDN.

What we collect

The honest answer: we collect nothing about you. There is no account system, no telemetry, no analytics script, no fingerprinting, and no backend service that sees your usage.

What we do
  • Serve you a static HTML/CSS/JS page
  • Load two public CDN resources
  • Process your APK entirely in your browser
  • Let you download analysis reports and extracted files
  • Store your theme preference if you ever set one (nothing else)
What we don't do
  • Send your APK, its contents, or its hash anywhere
  • Log your IP address or user agent for profiling
  • Use analytics, tracking pixels, or third-party scripts
  • Set advertising or cross-site cookies
  • Require an account, email, or login of any kind
  • Share or sell any information to third parties
  • Profile you, fingerprint you, or track you across sites

What leaves your device

When you load the page, your browser makes a few outbound requests for static assets. None of them carry your APK data, but they do carry a standard HTTP request that reveals your IP address to the CDN edge server.

Request Destination Contains your APK?
HTML, CSS, JavaScript of this site Web host serving the page No
Inter & DM Mono font files fonts.googleapis.com · fonts.gstatic.com No
JSZip library (~100 KB) cdnjs.cloudflare.com No
APK file contents Never sent — stays in your browser's memory Never sent
Analysis results Never sent — exported only when you click download Never sent
i
Every website sees your IP address

Loading any web page reveals your IP to that server — that's how the internet works. This site is no different in that respect. What's different is that nothing about what you analyze is ever sent, and no analytics script is loaded to profile your behaviour.

Going fully offline

Once the page has loaded and its resources are cached by your browser, you can disable your network connection entirely and still use the analyzer. Nothing about the analysis engine depends on the network at runtime.

Third-party resources

The site loads two third-party resources. Each has its own privacy policy that governs the requests your browser makes to their servers.

Google Fonts Serves the Inter and DM Mono typefaces used throughout the site. Google may log the request IP for abuse prevention purposes. See Google's privacy policy.
Cloudflare CDN (cdnjs) Serves the JSZip library used to open the APK's ZIP archive. Cloudflare may log request IPs for abuse prevention. See Cloudflare's privacy policy.

Self-hosting for maximum privacy

If you want absolutely no third-party requests, you can:

  1. Download the site files and the JSZip library yourself
  2. Host everything on your own machine or intranet
  3. Replace the Google Fonts link with locally hosted font files, or remove it entirely (the site falls back to system fonts)

The analyzer works identically with all third-party resources eliminated.

Hosting & server logs

Like every website, the server that hosts this page records basic HTTP request information in its access logs. This is standard and unavoidable — it's how the web serves files. Typical log entries include:

  • IP address making the request
  • Date and time of the request
  • Requested path (e.g. /apk-analyzer.html)
  • HTTP status code returned
  • User-agent string (browser and OS)
  • Referrer, if any

These logs are:

  • Not used for profiling — we don't build user profiles from them
  • Not correlated with your analysis — nothing about which APK you analyzed appears in any log
  • Rotated regularly — retained only as long as needed for basic operational debugging
  • Not sold or shared — with anyone
i
If you need absolute log invisibility

Download the site files and run them locally, or serve them on an internal network. Because the analyzer has no server-side component, it works identically when served from a USB stick or file:// URL.

Children's privacy

APK Analyzer Pro is a technical tool intended for developers, security researchers and other professionals. It is not directed at children under 13 (or under 16 in jurisdictions where that threshold applies).

Since we collect no personal information from anyone, we inherently collect none from children. If you believe a child has somehow provided information to us, there is nothing for us to retrieve or delete — but you may contact us and we'll confirm.

Security

The most secure server is no server

Because there is no backend that receives your APK, there is nothing for an attacker to breach in order to access your analyses. You cannot lose control of data that was never collected in the first place.

Client-side security considerations

  • Sandboxing — Your browser's JavaScript sandbox prevents the analyzer from reading files outside the one you explicitly select. It cannot browse your filesystem.
  • Memory only — The APK is loaded into JavaScript memory for processing. It isn't cached to disk by the analyzer itself.
  • No persistence — When you close the tab, everything the analyzer held in memory is released by the browser.
  • HTTPS — The site is served over HTTPS, so the static assets themselves cannot be tampered with in transit.
!
You are still analyzing untrusted code

The analyzer reads and decodes APK contents, but it never executes them. It does not run the app's code, does not load its native libraries, and does not open its resources. Analyzing a malicious APK is safe — running it is a different story.

Self-verification checklist

  1. Open DevTools (F12) → Network tab
  2. Analyze an APK
  3. Confirm no request carries the APK's bytes — only static assets
  4. Open DevTools → Application → Storage — confirm no cookies or localStorage entries created by the site
  5. Disconnect from the network and analyze another APK — it still works
